    And So It Begins…

    Welcome to my new corner of the internet!

    Setting up this blog was a fun exercise in using modern static site generation tools. I opted for:

    1. Hugo: Blazingly fast, written in Go, and incredibly flexible.
    2. Hextra Theme: A clean, minimal, and documentation-focused theme that works great for blogs too. Used as a Hugo Module for easy updates.
    3. GitHub Pages: Free and reliable hosting for static sites.
    4. GitHub Actions: Automated builds and deployments triggered by pushing content.

    The goal here is to keep things minimalist and functional. The focus should be on the content, not flashy distractions.
